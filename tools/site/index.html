egui-pop

An application framework and component library on egui.

egui-pop is for people building a real desktop tool on egui (an editor, a viewer, a control panel). It wraps your application's kernel through a host contract and gives it design tokens, themes and visual kits, commands with shortcuts, a workbench of panels, components (dialogs, palettes, sliders and inputs, trees and tables, text and code editors, an image viewport) and hooks at every step of its life. Your egui code keeps working inside it. MIT or Apache-2.0.
