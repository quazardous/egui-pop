# egui-pop-test

[![crates.io](https://img.shields.io/crates/v/egui-pop-test.svg)](https://crates.io/crates/egui-pop-test)
[![docs.rs](https://img.shields.io/docsrs/egui-pop-test)](https://docs.rs/egui-pop-test)

Test kit for egui-pop applications: themed egui_kittest harnesses, a
check that every interactive node has a name, an accessibility tree
dump, a double click that registers, keymap checks.

Part of [egui-pop](https://github.com/quazardous/egui-pop), an
application framework and component library for
[egui](https://github.com/emilk/egui). A dev-dependency for the tests of
an egui-pop application or extension, next to
[`egui-pop`](https://crates.io/crates/egui-pop).

Guide:
[Testing](https://github.com/quazardous/egui-pop/blob/main/docs/testing.md).
All of egui-pop's documentation: [the docs
index](https://github.com/quazardous/egui-pop/blob/main/docs/README.md).
