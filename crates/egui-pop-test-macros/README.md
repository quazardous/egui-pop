# egui-pop-test-macros

[![crates.io](https://img.shields.io/crates/v/egui-pop-test-macros.svg)](https://crates.io/crates/egui-pop-test-macros)
[![docs.rs](https://img.shields.io/docsrs/egui-pop-test-macros)](https://docs.rs/egui-pop-test-macros)

Attributes for the egui-pop test kit: `critical`, the mark of a test
that runs on every change, whatever a selective run would skip. Use it
through [`egui-pop-test`](https://crates.io/crates/egui-pop-test), which
re-exports it as `egui_pop_test::critical`.

Part of [egui-pop](https://github.com/quazardous/egui-pop), an
application framework and component library for
[egui](https://github.com/emilk/egui).

Guide:
[Testing](https://github.com/quazardous/egui-pop/blob/main/docs/testing.md).
