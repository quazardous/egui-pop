# egui-pop-tokens

[![crates.io](https://img.shields.io/crates/v/egui-pop-tokens.svg)](https://crates.io/crates/egui-pop-tokens)
[![docs.rs](https://img.shields.io/docsrs/egui-pop-tokens)](https://docs.rs/egui-pop-tokens)

Design tokens for egui-pop: a DTCG parser and resolver with themes,
densities, accents and contrast checks (no egui dependency).

Part of [egui-pop](https://github.com/quazardous/egui-pop), an
application framework and component library for
[egui](https://github.com/emilk/egui). Most applications depend on
[`egui-pop`](https://crates.io/crates/egui-pop), which re-exports this
crate as `egui_pop::tokens`; depend on `egui-pop-tokens` directly only
to use this layer alone.

Guide: [Design
tokens](https://github.com/quazardous/egui-pop/blob/main/docs/tokens.md).
All of egui-pop's documentation: [the docs
index](https://github.com/quazardous/egui-pop/blob/main/docs/README.md).
