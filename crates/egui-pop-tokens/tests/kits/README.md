# Kit fixtures

- `brand/`: a clean kit folder: `kit.json` with a manifest, a second
  token file, a face and its licence. `fonts/InterVariable-subset.ttf` is
  [Inter](https://github.com/rsms/inter) (SIL Open Font License 1.1, the
  kit's `LICENSE`), the subset `egui-pop-core`'s font tests use.
- `broken/`: one problem of each kind a folder can have.
- `not-a-kit/`: no `kit.json`, skipped by discovery.
