# egui-pop-wayland

[![crates.io](https://img.shields.io/crates/v/egui-pop-wayland.svg)](https://crates.io/crates/egui-pop-wayland)
[![docs.rs](https://img.shields.io/docsrs/egui-pop-wayland)](https://docs.rs/egui-pop-wayland)

The Wayland layer of egui-pop's image viewport: a subsurface under a
window, tagged through wp_color_management_v1, and the compositor's
preferred image description, with no egui dependency.

Part of [egui-pop](https://github.com/quazardous/egui-pop), an
application framework and component library for
[egui](https://github.com/emilk/egui). An internal layer of
[`egui-pop`](https://crates.io/crates/egui-pop), used by it on its
platform; applications do not depend on it directly.

Guide: [The image
viewport](https://github.com/quazardous/egui-pop/blob/main/docs/viewport.md).
All of egui-pop's documentation: [the docs
index](https://github.com/quazardous/egui-pop/blob/main/docs/README.md).
